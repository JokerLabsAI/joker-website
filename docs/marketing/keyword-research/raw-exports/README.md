# Preserve raw evidence here

Suggested filename:
`YYYY-MM-DD_TOOL_MARKET_CLUSTER_LANGUAGE_START_END.ext`

Example filename only:
`YYYY-MM-DD_GKP_CO_SOFTWARE_ES_YYYY-MM-DD_YYYY-MM-DD.csv`

Keep a matching settings note using `../templates/RESEARCH-RUN.md`. Record currency,
network, location targeting and reporting period. An export date is not its reporting
period. Keep CSV headers and original data unchanged; normalize only in workbook copies.

Expected first inputs:

- Keyword Planner discovery/historical-metric exports for CO, PE and MX separately.
- Optional Cali-targeted service export, kept separate from Colombia national data.
- Dated SERP notes/screenshots for priority phrases with actual/approximate location.
- Search Console query-filtered Pages or page-filtered Queries exports when available.
- Trends comparison exports with the exact comparison view and settings.

Use only business research data. Do not store credentials, billing details, raw
customer records or identifiable prospect notes in this repository. Review exports
before committing; keep confidential analytics in your team's restricted storage
and use an access-controlled reference rather than copying them into Git.
